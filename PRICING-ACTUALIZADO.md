## 🎯 Estrategia de Conversión

### Funnel de Precios

```
1. Starter GRATIS → Usuario registra sus 5 vehículos
2. Ve valor en el sistema (2-4 semanas)
3. Necesita más vehículos → Upgrade a Pro ($599)
4. Crece su negocio → Upgrade a Enterprise ($999)
```

**Starter → Pro:**
- Límite de 5 vehículos (cuando llega a 4, mostrar mensaje de upgrade)

- Mostrar feature multi-empresa
- Contacto proactivo de ventas cuando usa 12+ vehículos

### Validación de Límites

```typescript
// src/lib/validate-plan-limits.ts
export function validateVehicleLimit(user, newVehicleCount) {
  const plan = PLANS[user.plan];
  if (newVehicleCount > plan.maxVehicles) {
    return {
      allowed: false,
      message: `Has alcanzado el límite de ${plan.maxVehicles} vehículos. Upgrade a ${getNextPlan(user.plan)}.`,
      upgradeUrl: '/pricing'
    };
  }
  return { allowed: true };
}
```
