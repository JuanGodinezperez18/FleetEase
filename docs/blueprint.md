# **App Name**: FleetEase Manager

## Core Features:

- Admin Authentication: User authentication (login/logout) with session management.
- Vehicle Management: Add, edit, and delete vehicle information (make, model, year, etc.) including image upload.
- Driver Management: Create, modify, and remove driver profiles including license details and photo.
- Income/Expense Tracking: Record income and expenses with image attachment, linking to vehicles and drivers.
- Reporting Dashboard: Generate basic reports (monthly summary) for vehicles, expenses, and profitability, and the ability to print key screens.
- AI Expense Categorization: Use an AI-powered tool to categorize expenses based on attached receipts/photos and auto-fill data entries.
- Internal Notifications: Show reminders for maintenance schedules and license renewals within the app. Note: this is in-app only and will not generate emails.

## Style Guidelines:

- Primary color: Deep ocean blue (#2980B9) to convey trust, professionalism, and reliability.
- Background color: Light grey (#E5E7E9), providing a clean, neutral backdrop to improve legibility.
- Accent color: A vivid seafoam green (#73E2A1), draws attention to calls to action and important information.
- Headline font: 'Poppins', a geometric sans-serif (precise, contemporary feel); body font: 'PT Sans', a humanist sans-serif (modern look and some warmth).
- Use vector icons depicting cars and gears with a dark blue background and white or gray details.
- A modern, minimalist, professional layout with clear visual hierarchies and intuitive navigation.
- Subtle transition animations to create a polished user experience.
