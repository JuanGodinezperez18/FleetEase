## 🗄️ BASE DE DATOS SUPABASE

### Tablas Implementadas (22)

**Entidades Principales:**
- `companies` - Empresas (multi-tenant)
- `users` - Perfiles de usuario
- `clients` - Clientes
- `partners` - Socios/propietarios
- `vehicles` - Vehículos

**Operaciones:**
- `mileage_logs` - Registro de kilometraje
- `financial_records` - Registros financieros
- `financial_categories` - Categorías
- `credits` - Créditos
- `credit_payment_schedules` - Calendario de pagos

**Seguimiento:**
- `notifications` - Notificaciones
- `vehicle_assignment_logs` - Asignaciones
- `multas` - Multas de tránsito
- `gps_configs` - Configuración GPS
- `seguimientos` - Tracking GPS

**Documentación:**
- `documents` - Documentos adjuntos
- `message_templates` - Plantillas
- `message_logs` - Logs de mensajes

**Auditoría:**
- `company_change_logs` - Cambios en compañías
- `client_change_logs` - Cambios en clientes
- `audit_logs` - Logs de auditoría
- `fcm_tokens` - Tokens push

### Características de la BD

- ✅ **50+ índices** para optimización
- ✅ **12 triggers** para timestamps automáticos
- ✅ **40+ políticas RLS** para seguridad
- ✅ **Multi-tenant** por compañía
- ✅ **Soft delete** en todas las tablas
- ✅ **Auditoría** automática de cambios

## 🚀 HERRAMIENTAS DE MIGRACIÓN

### Scripts Disponibles

```bash
# Test de conexión
npm run test:supabase-connection

# Migrar datos
npm run migrate:supabase

# Exportar backup
npm run migrate:supabase:export

# Migración selectiva
npx tsx scripts/migrate-to-supabase.ts migrate clients,vehicles
```

### Flujo de Migración

1. **Exportar** datos de Firebase
2. **Transformar** camelCase → snake_case
3. **Importar** a Supabase con upsert
4. **Verificar** integridad de datos
